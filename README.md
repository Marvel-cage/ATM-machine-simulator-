# ATM Simulator - Built with the guidance of my former computer teacher📱

This is a full ATM logic system built by me on my laptop in JSS3 with a little help from my computer teacher. The program logic is 100% me

### Why I built this
My Computer teacher, Mr. Ola, gave this as assignment in JSS3. He left before SSS1. I thank him for introducing me to the programming world with such a massive project 

### Features
- PIN Authentication with 3-attempt lockout (uses `break` to exit loop)
- Balance check, Withdrawal, Deposit
- Inter-bank transfer with
- Change of Pin
- Input validation - prevents negative withdrawal
